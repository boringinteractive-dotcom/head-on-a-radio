Concept 2

Matrices (The Digital Grid)

Computers don't "see" drawings. They like numbers. A Matrix is a 2D grid of numbers.

Visual Matrix
5 0 9
7 3 1
4 4 2

Coordinates: M[row][col]

  • M[0][2] is Row 0, Col 2 -> 9
  • M[1][0] is Row 1, Col 0 -> 7

Concept 3

Adjacency Matrices

How do we store a Graph in a Matrix? Simple.

If Node i connects to Node j, set Matrix[i][j] = 1.
Otherwise, set it to 0.

Algorithm: Given an adjacency matrix, calculate the in-degree (arrows pointing IN) and out-degree (arrows pointing OUT) for each node.
Pseudocode
1. n = adjacency.length
2. inDegree = [0, 0, 0, 0]
3. outDegree = [0, 0, 0, 0]
4. for i from 0 to n-1:
5. for j from 0 to n-1:
6. if adjacency[i][j] == 1:
7. outDegree[i] = outDegree[i] + 1
8. inDegree[j] = inDegree[j] + 1
9. return inDegree, outDegree

Application

Paragraph Coherence

Graphs can analyze writing. Nodes are Nouns. Edges connect nouns in the same sentence.

Paragraph A (Coherent)

Swami woke up. The school headmaster was strict. Swami ran to school.

Result: One big connected graph!

Paragraph B (Disjoint)

The train was late. Blue Whales are big. I like ice cream.

Result: Many tiny disconnected islands.
