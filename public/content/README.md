# Content Folder

This folder contains HTML content files for course weeks.

## Structure

```
content/
  [course-slug]/
    week-1.html
    week-2.html
    ...
```

## Example

For CS50 course, create:
- `content/cs50/week-1.html`
- `content/cs50/week-2.html`

## Usage

1. Create a folder with your course slug (e.g., `cs50`)
2. Add HTML files named `week-[number].html`
3. The content will automatically load on the course page
