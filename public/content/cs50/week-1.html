Week 1: Introduction to Computer Science

Overview

Welcome to CS50! This week, we'll introduce you to the fundamentals of computer science and programming. We'll explore how computers think, what algorithms are, and write our first programs.

Topics Covered

  • Binary and how computers represent information
  • Algorithms and computational thinking
  • Introduction to C programming language
  • Variables, data types, and operators
  • Conditional statements and loops

Example: Hello World

Let's write our first C program:

#include <stdio.h>

int main(void)
{
    printf("Hello, World!\\n");
    return 0;
}

Practice Problems

  1. Write a program that prints your name
  2. Create a program that asks for user input and greets them
  3. Build a simple calculator that adds two numbers
